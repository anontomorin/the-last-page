## 1. 风格定义（Style Bible）

### 1.1 一句话风格

**民国中国小镇的棕褐色银盐老照片**——像从一本 1935 年的档案相册里取出来的纸面，
柔和、克制、微微褪色，永远不恐怖、不戏剧化。

### 1.2 色板

| 用途 | 值 | 说明 |
|---|---|---|
| 纸面高光 | `#F4F1EA` | 相纸边缘 / 天空过曝区 |
| 纸面中间调 | `#C9B896` | 主体受光面 |
| 棕褐主调 | `#8A6F4D` | 全图主导色温（sepia 基准） |
| 暗部 | `#3E342A` | 阴影 / 门洞 / 树影 |
| 最深黑 | `#241F18` | 仅小面积（窗框、砖缝） |
| 点缀暖色 | `#B98A2F` | 极少：灯光、金色反光 |

> UI 令牌（`tokens.json`）管界面配色；本表只管**照片内部**的色调目标。

### 1.3 光线规则（全项目统一）

- **唯一光源：上午柔和自然光**（东/东南向窗光或天光）。
- 允许：轻雾、薄云漫射、逆光剪影（远景）。
- 禁止：夜景、硬光直射、强投影、霓虹、烛光戏剧光。

### 1.4 镜头与构图规则

| 类别 | 规则 |
|---|---|
| 场景图 | 3:2 横幅（1536×1024 生成）+ 竖档（1024×1536）；地平线放中下 1/3；**留出干净的中景区域** |
| 肖像 | 3:4（768×1024）+ 1:1（768×768）；胸像以上；视线看向画面外或微垂，**不看镜头** |
| 物件特写 | 近 45° 俯角或平视；主体占画面 60–80% |
| 颗粒 | 均匀细颗粒（后处理统一叠加，提示词只提「胶片颗粒」） |

### 1.5 质感关键词（提示词里逐字使用）

```
民国中国小镇，棕褐色调银盐老照片，胶片颗粒，柔和自然光，
轻微褪色，低饱和，克制的档案质感。画面中不出现任何可读文字、数字、水印、
logo、边框、现代物品。
```

### 1.6 负面词固定段（每次都带）

```
无可读文字、无数字、无水印、无 logo、无边框、无现代元素、非恐怖氛围、非末日、非赛博霓虹
```

> **这条负面词是必需的，但实测不足够**（见 §4「P11 事故记录」）：模型会把提示词本身
> 当成画面内容画出来（bg_ending 首版把描述句「春日清晨窗台…」原样写成了三行诗句），
> 且生成服务会在每张图右下角贴一枚「AI生成 / WORKBUDDY>\_」角标。
> 对策两条：① 提示词只写**具体物理对象**，不写「质感 / 档案线」这类抽象短语；
> ② 后处理管线**默认**执行 `dewatermark()`，不靠人记得加参数。

### 1.7 正 / 负例句

**✅ 正例**（主体段写法）：

> 旧钟楼立于石板街角，砖砌塔身有一道拱形木门，门前一条长椅；
> 晨光从画面左侧照来，远景街道微雾；平视中景构图，塔身放在画面右侧三分之二处，
> 左侧留出干净的街道空间；保持与参考图完全一致的老照片风格。

**❌ 负例**（不要这样写）：

- 「时钟指针指向 7 点 17 分」——**答案进图 = 致命违规**（§6.1）
- 「公告栏上写着……」——任何可读文字都不允许
- 「恐怖的、阴森的、血迹」——氛围越界
- 「高清、8K、锐利」——破坏银盐质感

### 1.8 答案隔离硬约束（§6.1 复述，违者废弃重做）

| 对象 | 规则 |
|---|---|
| 钟面时间 | ❌ 图内不得出现 7:17 或任何「正确的」时间；钟面指针由 DOM 绘制 |
| 公告栏第七行 | ❌ 图内文字只能是模糊伪字；真实文字是 DOM |
| 折痕数字 / 日期天气 | ❌ 一律 DOM |
| 地图 | ❌ 不出图，必须 SVG |
| 图标 | ❌ 不出图，内联 SVG |

1. **风格圣经** —— 本文档 §1。
2. **定调 hero** —— 已审定为存量 `cover_archive.webp`（零积分；若未来重做，允许 roll 6–10 次）。
3. **以图生图派生** —— ImageGen `image1` = 上表对应参考图；`input_fidelity: high`；
   提示词 = §1.5 质感前缀 + 主体段（§1.7 模板）；人物必须写「与参考图中同一张脸」。
4. **确定性后处理** —— `tools/art-pipeline.py`：sepia 统一 → 颗粒 → 暗角 → **去水印**
   → 裁切 → 缩放 → WebP（q82–85）导出 + 写 manifest。**「风格一致」由这一步保证，不靠提示词。**
   > 去水印自 P11 起是 `process` 的默认步骤（`--no-dewm` 可跳过）：见 §4 事故记录。
5. **拼版质检 + 导出** —— `tools/art-pipeline.py contact-sheet` 拼版 → 人工审核 → 体积核对。

## 4.2 P11 事故记录：提示词被画进画面 + 全站角标水印

用户指着 `bg_ending_raw.png` 提了两条：「这张照片中不应有文字」「第六幕开始时照片应显示横板」。
查下来是**三个独立缺陷**叠在一起，其中两个是普遍性的：

| # | 缺陷 | 范围 | 根因 | 处置 |
|---|---|---|---|---|
| 1 | 画面里出现了三行诗（`春日清晨窗台，沐浴晨的春房的晨光，老镇屋顶光与淡淡的山影，春日精新的档案线的质感。`） | 仅 bg_ending | 提示词末句「春日精新的档案线的质感」是**抽象短语**，模型把它当正文画了出来 —— 典型的提示词文案泄漏。§1.6 的「无可读文字」负面词没能压住 | 重做（新提示词只写具体物理对象） |
| 2 | 右下角「AI生成 / WORKBUDDY>\_」角标 | **全部 47 张** | 生成服务的角标模板，@1536 画布约 110×51px、距右/下各 10px，随画布等比缩放；存量图另有一种更淡的方框变体（约 80×30 @1280） | 管线新增 `dewatermark()`，`process` 默认执行；8 张底纹已全部重出 |
| 3 | 结局主视觉渲染成 635×922 竖版条 | `.end-hero` | `img` 带 `width/height` 属性防 CLS，CSS 只锁 `width:100%` → 属性里的 922 把高度钉死，`aspect-ratio:16/9` 被整个忽略（与 `.map-room img` 同一处陷阱，P5 只补了后者） | `.end-hero` 补 `height:auto`，去掉与之冲突的 `aspect-ratio/object-fit` |

**去水印几何**（`tools/art-pipeline.py` 的 `DEWM`）：取右下角 13%×8.5% 矩形（含两种变体余量），
用「1/8 降采样上的边界调和扩散」填出周边纹理的低频延续，再双三次放大回填，上/左边界
各留 28% 羽化；最后把填块均值对齐到正上方一条的均值（否则会出现一块比周围深/浅的矩形）。
**不用镜像**：老地图的裂纹、衣褶、纸张边缘这类有结构的角落，镜像会造出可见的万花筒重影。
