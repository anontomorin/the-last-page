# 最后一页没有写完

> 叙事型 ARG / 数字档案探索解谜游戏 · 纯前端 · 无需构建

你是「青年数字档案计划」的志愿者，正在整理编号 **ARCHIVE A-017** ——《林远个人档案》：
31 篇日记、12 张照片、4 封书信、1 张旧地图，以及一页显示"损坏"的 **第 32 页**。

通过阅读、观察、关联与交叉验证，还原林远、周宁、陈川、李禾四位年轻人在某个三月的故事：照片背面折痕里的数字、停在 7:17 的旧钟、公告栏被水渍晕开的第七行、三个人记忆中互相矛盾的"那一天"……

主观记忆会偏移，唯有证据链能逼近真实。而当你修复了最后一页，会发现空白本身就是答案——**最后一句，由你来写。**

*本作品人物与事件均为虚构。*

## 快速开始

无需安装任何依赖，两种方式任选：

```bash
# 方式一：直接双击 index.html（支持 file:// 协议）

# 方式二：本地静态服务
python3 -m http.server 8000
# 打开 http://localhost:8000
```

线上试玩：将仓库开启 GitHub Pages（Settings → Pages → main 分支根目录）即可。

## 玩法

- **阅读** 日记 / 信件，**观察** 照片（翻面、折痕、放大、档案信息）
- 在 **地图** 上进入旧钟楼、老街、渡口等场景，与场景物件互动
- 在 **人物** 页确认四人身份，使用【追踪】反查相关资料
- 在 **证据板** 亲手**建立线索之间的关系**（选择「支持 / 矛盾 / 补充 / 同一」并写出理由），
  系统会判定关系是否成立——**第三幕主线要求你先连出三条人物身份关系，才会推进**
- 在 **时间线** 完成交叉验证（先按天色分堆，再给每一堆定日子）：
  卡片不再直接给出日期，需要点卡片上的「↗ 查看原件」回到照片背面 / 折痕 / 编号说明去读
- 修复 **PAGE_032.dat**，写下最后一页，达成结局（含隐藏结局）
- 卡住时每处谜题提供 **三级渐进提示**

### 原件与证据的双向导航

谜题卡片（时间线）与原件（照片 / 信件 / 日记 / PAGE_032）之间可以互相跳转：

- 时间线卡片 →「↗ 查看原件」→ 打开对应照片 / 日记 / 信件本体
- 原件查看器工具栏 →「◈ 用于时间线」/「◈ 证据板上的关联」→ 回到它在谜题里的位置（高亮闪烁）

## 双人拼卷（需语音连线）

开局可选择 **执笔者卷 A** 或 **记录者卷 B**，两人各玩一半档案：

> 完整流程见 **[DUO_GUIDE.md · 双人模式通关指南](DUO_GUIDE.md)**


| | 执笔者卷 A | 记录者卷 B |
|---|---|---|
| 手里有 | 日记、信件（文字） | 照片、地图（影像） |
| 看不到 | 任何照片 | 任何信件；日记只有「编目梗概」 |
| 现场 | 进不去（留在馆里翻纸页） | 钟楼、老街、渡口都由 ta 走 |

**语音通话是主渠道。** 工作台右上角「通话」面板只做两件事：

- **念给 ta 听** —— 列出你手里已经掌握、而对方正等着的信息，给出可以直接念出口的台词；支持浏览器朗读与一键复制。
- **记下 ta 说的** —— 把你在电话里听到的内容照实写下（不必一字不差），系统只负责确认你听懂了。提示分两级：先只指方向，再点一次「还是没听清」才给到接近答案的那一步。

六幕里每一幕都有必须靠对方才能越过的一环：第一幕双向交换折痕与日记、第二幕的钟声次数与公告栏、第三幕的姓名落款、第四幕时间线的**双向证据核对（日期、背题、折痕与天气观察分散在两卷）**、第五幕第 32 页每一段都缺一样对方的东西、第六幕合卷。

> **两卷都不能单人通关。** 这不是倡议而是机制：每一幕都有一道门，钥匙只握在对方手里——A 缺日子、B 缺字，谁先开口谁先过。卡住时打开「通话」，面板顶部会直接写出「你卡在等 ta 念：××」。反过来，也没有任何一样信息是拿不到的：你缺的那样，一定完整地躺在对方档案里，ta 念出来即可。

面板最底部的 **碎片码** 只是「实在无法通话时」的兜底通道（默认折叠）；第六幕结算页则把碎片码作为首选——面板里可直接一键复制，每问限 40 字以保证码足够短。

## 特性

- 纯原生前端（HTML/CSS/JS），无框架、无构建、无后端
- 完整六幕剧情 + 非线性档案探索
- 主动推理：证据板由玩家亲手连关系并判定（不是看预设连线）
- 原件 ↔ 谜题双向导航：卡片能回原件，原件能回它在谜题里的位置
- 分级推理反馈：分组 / 天气 / 日期 / 证据关系各自给出针对性指引
- Web Audio 程序化音效（无任何音频文件）
- localStorage 自动存档，刷新不丢进度
- 隐藏 ARG 层：URL 路径 `#/archive/A-017/page/032`、HTML 注释、CSS 变量
  （控制台读取或键入 `032`）中的碎片线索，指向隐藏结局
- 响应式适配 ≥320px，键盘可达（Tab 全程可见焦点），尊重「减少动态效果」偏好
- 结局页支持打印为实体纪念页

## 可复现测试环境

游戏本体是纯前端、零依赖的；测试环境只需 Node（用于跑断言）与本机 Chrome（用于真实 UI 通关）。

```bash
npm test                 # 一次跑完：语法自检 + 数据自检 + 听写校验 + 六幕通关
npm run test:dictation   # 只跑双人「听写校验」（离线，无需浏览器）
npm run test:playthrough # 双开 A/B 卷，用真实 UI 完整通关六幕（需 Chrome）
npm run serve            # 起本地静态服务（默认 127.0.0.1:8123）
```

**`npm test` 的四层：**

| 层 | 内容 | 依赖 |
|---|---|---|
| 1 | 语法自检：编译 `js/**` 全部脚本，等价 `node --check` | 无 |
| 2 | 数据一致性：校验线索 / 证据关系 / 时间线卡片引用的 id 全部存在 | 无 |
| 3 | 听写校验：正确答案、同义答案、常见误答三组向量 | 无 |
| 4 | 六幕通关：双开浏览器上下文，A/B 两卷各自独立存档，全流程真实点击 | Chrome + playwright-core |

**依赖路径可覆盖**（换机 / CI 时）：

```bash
CHROME_PATH="/path/to/chrome" \
PLAYWRIGHT_PATH="/path/to/node_modules/playwright-core" \
TEST_PORT=8123 \
SKIP_PLAYTHROUGH=1 \        # 跳过第 4 层
npm test
```

自动化脚本会自动拉起本地静态服务（`_playtest/serve.js`，零依赖），无需先手动起服务。
